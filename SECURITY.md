# Security policy

Do not report security vulnerabilities in public issues, pull requests, or discussions.

Use **Security → Advisories → Report a vulnerability** on this repository to send a private report. The repository owner should enable GitHub private vulnerability reporting under **Settings → Code security and analysis** before making the repository public. If the private reporting option is unavailable, contact the repository owner through their GitHub profile to arrange a private channel; do not include vulnerability details in public messages.

This repository does not publish a response-time commitment. Please include only the information needed to understand and reproduce the issue in the private report.
