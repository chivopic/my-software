# Development and signing

## Xcode project

Open `Memento.xcodeproj` in Xcode 16 or later, select the `Memento` scheme, and choose an iOS 17 or later simulator. The checked-in project is generated by `scripts/generate-project.py`, which uses only Python's standard library:

```bash
python3 scripts/generate-project.py --check
```

The `--check` option verifies that the checked-in Xcode project and scheme match the generator. Run `python3 scripts/generate-project.py` to regenerate them after changing project inputs. No XcodeGen, CocoaPods, or third-party Swift packages are required.

The generator sets `ARCHS` to `$(ARCHS_STANDARD)` and disables active-architecture-only builds for the project. App, Share Extension, Widget, and the local `MementoCore` package must use matching simulator slices; changing only the generated project file is not sufficient. The simulator script repeats these settings for its `xcodebuild` invocation. This addresses the configuration gap behind reports of the Share Extension requesting an x86_64 module while the package produced arm64 only; an Xcode simulator run is still needed to verify the result.

## Device and extension signing

The app, Share Extension, and Widget use these default identifiers:

| Target | Bundle ID |
| --- | --- |
| Memento | `com.chivopic.memento` |
| MementoShare | `com.chivopic.memento.share` |
| MementoWidget | `com.chivopic.memento.widget` |

All three use the App Group `group.com.chivopic.memento`. To run on a device or sign the extensions, select an Apple development team for the targets and make sure the App Group is registered for that team. The group must match in the Xcode entitlements and app code; if unavailable, the app reports the error rather than using a separate store the extensions cannot access.

If these identifiers are not available to your team, update them consistently:

- Bundle IDs in `scripts/generate-project.py`.
- App Group in `Resources/Memento.entitlements` and `Core/Storage/Capture.swift` (`SharedContainer.groupID`).
- If renaming the product, the backup type identifier in `Resources/App-Info.plist` and `Features/Settings/ExportDocuments.swift`.
