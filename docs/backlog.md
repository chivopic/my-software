# Backlog

V0 期间冒出来的想法放这里，不要顺手实现。每条写清楚「解决什么问题」，而不只是「加个什么功能」。

格式：`- [来源版本] 想法 —— 解决什么问题`

## 待评估

- [V0] 双向链接 `[[Note]]` —— 让笔记之间的关系可导航，而不是只靠标签
- [V0] Task 与 Note 的关联（做某任务时产出的笔记）—— Daily Review 里能回答「这周做的事留下了什么」
- [V0] ActivityLog 表 —— V2 统计需要历史行为，越早开始记越好（见 docs/03 第 5 节）
- [V0] 番茄钟 / 实际用时记录 —— 让 Focus Time 有真实数据来源
- [V0] 键盘驱动的全局命令面板（不只是 Capture，还能跳转/执行命令）
