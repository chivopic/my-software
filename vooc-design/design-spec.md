# VOOC macOS 笔记软件设计文档

> 状态：概念设计 v0.1
>
> 平台：macOS 14+
>
> 技术方向：Swift 5.10+ / AppKit / Swift Concurrency
> 产品名称：VOOC

## 1. 产品愿景

VOOC 是一款本地优先、键盘优先的 macOS 笔记软件。它借鉴 Obsidian 的双向链接、本地 Markdown 与知识网络思想，但不复制其界面：VOOC 更安静、更接近纸张，也更符合 macOS 原生应用的操作习惯。

核心体验可以概括为：**像整理桌面卡片一样组织知识，像在纸上书写一样专注。**

### 1.1 设计原则

1. **内容先于工具**：编辑区始终是视觉中心，控件在不需要时保持克制。
2. **本地数据可掌控**：笔记以普通 Markdown 文件保存，附件与笔记同库管理。
3. **连接自然发生**：输入 `[[` 即可链接笔记，反向链接不打断写作。
4. **键盘完成主流程**：搜索、建笔记、切换、链接、移动均有快捷键。
5. **原生而非网页拟态**：窗口、菜单、工具栏、侧栏、文本系统遵循 macOS 习惯。

## 2. V0 范围

### 2.1 包含

- 打开或创建本地 Vault 文件夹
- Markdown 编辑、阅读预览与自动保存
- 文件夹、标签、收藏、最近笔记
- `[[双向链接]]`、反向链接面板与未解析链接提示
- 全库搜索、快速打开、命令面板
- 附件拖放与相对路径引用
- 浅色、深色及跟随系统主题
- 基础偏好设置与快捷键说明

### 2.2 暂不包含

- 云同步、账号系统与团队协作
- 插件市场和第三方脚本执行
- 移动端与 Web 端
- AI 写作或在线内容生成
- 数据库视图、白板与发布站点

## 3. 信息架构

### 3.1 主窗口

主窗口使用可折叠三栏结构：

| 区域 | 建议宽度 | 内容 |
| --- | ---: | --- |
| 导航侧栏 | 220 pt | Vault、搜索、最近、收藏、标签、文件树 |
| 笔记列表 | 300 pt | 当前集合、排序、笔记摘要与更新时间 |
| 编辑器 | 自适应，最小 560 pt | 标题、属性、正文、状态栏 |

右侧信息检查器以抽屉形式出现，展示大纲、反向链接与文档信息，不常驻挤压正文。

### 3.2 核心页面

- **全部笔记**：按更新时间展示所有 Markdown 文件。
- **最近使用**：突出最近打开和最近修改的内容。
- **收藏**：用户主动标记的重要笔记。
- **标签**：标签列表及其笔记集合。
- **搜索结果**：标题、正文与路径命中，显示上下文片段。
- **图谱**：作为 V1 候选；V0 只实现链接与反向链接，不做可视图谱。

## 4. 关键交互

### 4.1 快速记录

- `⌘N` 在当前文件夹创建笔记并聚焦标题。
- `⌥⌘N` 打开轻量浮层，仅输入标题与正文，保存后不离开当前笔记。
- 新笔记默认命名为“未命名笔记”，首次输入标题后同步更新文件名。

### 4.2 快速打开与命令面板

- `⌘O` 打开快速打开浮层，可按标题、路径、标签模糊搜索。
- `⌘K` 打开命令面板，支持“新建笔记”“切换主题”“移动笔记”等动作。
- 上下方向键选择，`↩` 确认，`⌘↩` 在新窗口打开，`Esc` 关闭。

### 4.3 编辑与链接

- 编辑器采用单一连续文本面，不在 V0 实现逐块编辑器。
- 输入 `[[` 展示笔记建议；输入 `#` 展示标签建议。
- 点击已解析链接打开目标；按住 `⌘` 点击在新窗口打开。
- 自动保存采用 500 ms 防抖；窗口底部显示“已保存”或明确错误。

### 4.4 空状态与错误恢复

- 无 Vault：展示“打开文件夹”和“创建 Vault”两个明确入口。
- 无笔记：提供新建笔记按钮与 `⌘N` 快捷键提示。
- 搜索无结果：保留查询词，并提供创建同名笔记入口。
- 文件被外部修改：先暂停覆盖，提供比较、重新载入与另存副本。
- 文件不可写：正文保持可复制，并展示可恢复的非模态错误条。

## 5. 视觉方向

### 5.1 气质

关键词：**暖米色、安静、编辑感、纸张纹理、克制的艺术性、长期使用不疲劳**。

界面采用低对比暖色层级，避免纯白与纯黑。品牌符号是一张折叠成字母 **V** 的纸页：既像打开的笔记，也像两条知识路径汇合。圆角方形底座适配 macOS App Icon，内部的墨色线条在小尺寸仍可识别。

### 5.4 字体与排版

- UI：SF Pro Text，13 pt，跟随系统 Dynamic Type 与辅助功能字号。
- 标题：New York，28 pt Semibold，营造轻微出版物气质。
- 正文：New York，16 pt，行高 1.65；代码使用 SF Mono 13 pt。
- 正文最大阅读宽度 760 pt；宽窗口中居中，避免形成过长行。

### 5.5 动效

- 侧栏展开、检查器出现：180 ms ease-out。
- 快速打开：轻微 0.98 → 1 缩放与 120 ms 淡入。
- 减少动态效果开启时，仅保留透明度过渡。

## 6. 品牌与图标

### 6.1 Logo

文字标采用大写 `VOOC`。两个 `O` 暗示相互连接的笔记节点，字距略宽，整体沉静而不偏科技品牌。

### 6.2 App Icon

- 米白纸页折成 V 形，边缘带细微墨线。
- 底层为陶土橙到暖赭色的柔和渐变。
- 纸页中心有一条短横线，暗示正文，也避免符号被误读为普通字母。
- 16 px 小尺寸版本去除纹理与细线，仅保留 V 形剪影。

## 7. AppKit 实现建议

### 7.1 窗口与布局

- `NSWindowController` 管理主窗口与多窗口生命周期。
- `NSSplitViewController` 实现导航侧栏、笔记列表与编辑器三栏。
- 导航与列表优先使用 `NSOutlineView` / `NSTableView`，获得原生键盘导航与性能。
- 右侧信息检查器使用独立 child view controller，并通过 toolbar item 控制显隐。

### 7.2 编辑器

- 基于 TextKit 2：`NSTextView` + `NSTextContentStorage`，保留大文件性能空间。
- Markdown 文件读取与保存放在 actor 隔离的文档仓库中。
- 使用 `NSFileCoordinator` 与文件系统事件监听处理外部编辑。
- 搜索索引在后台 Task 中增量更新，UI 更新回到 `MainActor`。

### 7.3 数据边界

- Vault 内 Markdown 与附件是唯一真源。
- 应用支持数据放在 Application Support，仅保存窗口状态、收藏、最近记录和索引缓存。
- 所有缓存可重建；删除缓存不得损坏用户内容。

## 8. 无障碍与 macOS 一致性

- 所有图标按钮必须有 Accessibility Label 与 Tooltip。
- 完整支持 Full Keyboard Access、VoiceOver、增加对比度与减少透明度。
- 颜色不作为唯一状态表达；收藏、错误、保存状态都同时使用图标或文本。
- 菜单栏暴露主要命令与快捷键，避免只有隐藏手势才能完成的操作。

## 9. 后续确认点

进入编码前建议确认以下三点：

1. 品牌图标采用“折纸 V”方向，还是更抽象的“双节点连接”方向。
2. 编辑器默认使用“纯编辑”还是“实时 Markdown 装饰”模式。
3. V0 是否需要 iCloud Drive 文件夹兼容测试；不内建同步，但可操作用户选择的 iCloud 文件夹。
