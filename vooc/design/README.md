# VOOC design previews

This directory contains concept designs for VOOC, a local-first Markdown notebook for macOS. The runnable Swift and AppKit prototype is in [`../macos`](../macos/README.md); the images below are design previews, not screenshots of the current app.

## Main window

The proposed three-column layout keeps vault navigation, note search, and editing in one window.

![VOOC three-column main window concept](./previews/01-main-window.svg)

## Quick open

The quick-open concept explores keyboard-first search across a local vault.

![VOOC quick-open concept](./previews/02-quick-open.svg)

## Brand board

The board collects the proposed mark, icon direction, and warm neutral palette.

![VOOC brand board concept](./previews/03-brand-board.svg)

See [`design-spec.md`](./design-spec.md) for the product direction, information architecture, and implementation notes.
